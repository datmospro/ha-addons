# Mesa · Recetas

Consulta el [manual completo](https://github.com/datmospro/ha-addons/blob/main/mesa_recetas/README.md) para instalar, configurar las alarmas Android e importar recetas.

Primeros pasos: **Abrir interfaz web → Ajustes → Guardar comensales, objetivos y móviles → Probar alarma → Semana → Generar menú**.

Los ejemplos incluyen macros estimados y fotos ilustrativas. Comprueba las alarmas en los teléfonos bloqueados: se envían mediante Home Assistant Companion y necesitan conexión y permisos.
