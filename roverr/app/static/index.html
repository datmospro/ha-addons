Guía de configuración en Windows

1. El script: Guarda roverr_receptor.py en el PC Windows de destino.

2. Abre el Programador de tareas: Pulsa Crear tarea (no una tarea básica).

3. Pestaña General: Marca "Ejecutar tanto si el usuario inició sesión como si no" y "Ejecutar con los privilegios más altos".

4. Pestaña Desencadenadores: Nuevo ➔ Al iniciar el sistema.

5. Pestaña Acciones: Iniciar un programa.
  • Programa: Introduce la ruta de python.exe (no pythonw.exe).
  • Argumentos: "roverr_receptor.py"
  • Iniciar en: La carpeta que contiene el script.
