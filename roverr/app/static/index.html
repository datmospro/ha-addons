Remote Copy Receptor (Windows Only)

Offload the file copy process to a background script running natively on the destination PC to eliminate network bottleneck.

Windows Setup Mini-Guide

1. The Script: Place roverr_receptor.py on your Windows destination PC.

2. Open Task Scheduler: Click Create Task (not basic).

3. General Tab: Check "Run whether user is logged on or not" (this secretly hides the console window) and "Run with highest privileges".

4. Triggers Tab: New ➔ At startup.

5. Actions Tab: Start a program.
  • Program: Put the path to your normal python.exe (NOT pythonw.exe).
  • Arguments: "roverr_receptor.py"
  • Start in: The folder where the script is located.
