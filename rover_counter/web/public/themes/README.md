# Recursos de los temas

Fondos originales y palos de baraja española generados para Rover Counter a partir de los bocetos de Mesa de cartas y Taberna de fantasía. No contienen textos de interfaz: nombres, puntos y controles se renderizan en HTML.

- mesa-v1.webp: tapete verde, madera, esquinas de latón y cartas en los bordes.
- taberna-v1.webp: madera tallada, piedra, velas y cristales azules.
- palos-v1.webp: atlas transparente 2×2 (oros, copas, espadas y bastos).

Los recursos se sirven localmente con el addon. El estilo inicial no requiere descargar los fondos nuevos. Los originales PNG se conservan fuera de los archivos de distribución.
